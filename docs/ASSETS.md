# Asset and dependency provenance

The round capybara and scruffy lynx designs, articulated meshes, stitched kits, Rush Arena, turf, netting, lighting, spectator scenery, markings, football graphics, broadcast overlays and sound effects were authored procedurally for this project. Their source lives in `src/art.ts`, `src/characters.ts`, `src/stadium.ts`, `src/renderer.ts`, `src/audio.ts`, `src/styles.css`, and `index.html`. Text uses fonts already installed in the viewer’s operating system. The packaged art consists of project-native geometry and textures generated by the game.

The ten hero portraits, face profiles, builds, and signature accessories use cast data in `src/heroes.ts`. `src/portraits.ts` draws the portraits in Canvas 2D. `src/hero-face.ts` and `src/hero-gear.ts` build the faces and accessories into the existing 3D character rig. `src/arena-crowd.ts` constructs individual supporters from instanced silhouettes and palettes.

The surrounding town, hills, park, fountain, and sky are generated in `src/surroundings.ts` from shapes, materials, and a seeded layout. The recording loads these assets from the game bundle.

`public/voice/rush-radio.wav` contains 365 English clips from `src/commentary-lines.json`, including 140 calls and replies for the ten players. The clips were synthesized with `kokoro-js` 1.2.1 and Kokoro-82M v1.0 ONNX q8. Mick and Emma use `am_michael` and `bf_emma`. The model and tool are Apache-2.0. See `public/licenses/kokoro.txt`. The build bundles the generated audio and a cue map. The model, synthesis library and voice weights are used only during generation. [Kokoro model](https://huggingface.co/hexgrad/Kokoro-82M) · [ONNX distribution](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX) · [JavaScript tool](https://github.com/hexgrad/kokoro/tree/main/kokoro.js)

To regenerate the commentary track, install `kokoro-js` with `npm install --prefix .tooling/commentary kokoro-js@1.2.1` and run `node scripts/generate-commentary.mjs`. This optional step downloads the model once. When adding lines after the existing entries and keeping their text and voices intact, run with `--append` to reuse the existing clips. The game and normal build use the bundled asset.
