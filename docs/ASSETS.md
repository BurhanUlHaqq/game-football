# Asset and dependency provenance

The round capybara and scruffy lynx designs, articulated meshes, stitched kits, Rush Arena, turf, netting, lighting, spectator scenery, markings, football graphics, broadcast overlays and sound effects were authored procedurally for this project. Their source lives in `src/art.ts`, `src/characters.ts`, `src/stadium.ts`, `src/renderer.ts`, `src/audio.ts`, `src/styles.css`, and `index.html`. Text uses fonts already installed in the viewer’s operating system. The packaged art consists of project-native geometry and textures generated by the game.

The ten hero portraits, face profiles, builds, and signature accessories use cast data in `src/heroes.ts`. `src/portraits.ts` draws the portraits in Canvas 2D. `src/hero-face.ts` and `src/hero-gear.ts` build the faces and accessories into the existing 3D character rig. `src/arena-crowd.ts` constructs individual supporters from instanced silhouettes and palettes.

The surrounding town, hills, park, fountain, and sky are generated in `src/surroundings.ts` from shapes, materials, and a seeded layout. The recording loads these assets from the game bundle.

`public/voice/rush-radio.wav` contains 452 English performances for Mick and Emma. The text and exact setup/answer pairs live in `src/commentary-lines.json`. Kokoro-82M v1.0 ONNX q8 with `kokoro-js` 1.2.1 supplies the phonetic guides (`am_michael` and `bf_emma`). The project’s 20-band vocoder in `scripts/cartoon-voice.mjs` uses these guides to articulate a reed-like oscillator for Mick and a bell-like oscillator for Emma. It blends those instrument tones with pitch-shifted, waveform-aligned syllables, follows sentence inflection, and lifts the pitch on goal calls. A few introductions and punchlines end with a short spring or bell sound. The game packages the rendered PCM and its cue times. The model and tool use Apache-2.0. [License](../public/licenses/kokoro.txt) · [Kokoro model](https://huggingface.co/hexgrad/Kokoro-82M)

To regenerate the commentary track, install `kokoro-js` with `npm install --prefix .tooling/commentary kokoro-js@1.2.1` and run `node scripts/generate-commentary.mjs`. This optional step downloads the model once. Use `--append` to reuse locally cached phonetic guides whose IDs, voices and scripts match. Both commands render the complete cartoon bank. The game and normal build use the bundled asset.
