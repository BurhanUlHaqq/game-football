# Asset and dependency provenance

The round capybara and scruffy lynx designs, articulated meshes, stitched kits, Rush Arena, turf, netting, lighting, spectator scenery, markings, football graphics, broadcast overlays and sound effects were authored procedurally for this project. Their source lives in `src/art.ts`, `src/characters.ts`, `src/stadium.ts`, `src/renderer.ts`, `src/audio.ts`, `src/styles.css`, and `index.html`. Text uses fonts already installed in the viewer’s operating system. The packaged art consists of project-native geometry and textures generated by the game.

The ten hero portraits, face profiles, builds, and signature accessories use cast data in `src/heroes.ts`. `src/portraits.ts` draws the portraits in Canvas 2D. `src/hero-face.ts` and `src/hero-gear.ts` build the faces and accessories into the existing 3D character rig. `src/arena-crowd.ts` constructs individual supporters from instanced silhouettes and palettes.

The surrounding town, hills, park, fountain, and sky are generated in `src/surroundings.ts` from shapes, materials, and a seeded layout. The recording loads these assets from the game bundle.

`public/voice/rush-radio.wav` contains 480 original English performances for Jom the cat and Jerry the mouse. Kokoro-82M v1.0 ONNX q8 and `kokoro-js` 1.2.1 provide the speech guides. The project’s processor uses gently pitched, waveform-aligned syllables and a low-level harmonic character tone. It keeps consonants clear and tapers the starts and ends of the clips. The game ships the rendered PCM, the matching cue sheet and the two original booth portraits. [Model license](../public/licenses/kokoro.txt) · [Kokoro model](https://huggingface.co/hexgrad/Kokoro-82M)

The 54 local stereo Ogg recordings in `public/music/stadium-band/` contain six original scores. Each has eight arrangements, an aligned second band part, and a reel of seven event cues. The notes, instrumentation, phrasing and mix are authored in `scripts/stadium-arrangements.mjs` and `scripts/record-stadium-band.mjs`. The sessions use GeneralUser GS 2.0.3 by S. Christian Collins, rendered with FluidSynth 2.6.2. The instrument license permits commercial music recordings. [Instrument library](https://www.schristiancollins.com/generaluser) · [Instrument license](https://github.com/mrbumpy409/GeneralUser-GS/blob/main/documentation/LICENSE.txt)

To reproduce the recordings, run `node scripts/record-stadium-band.mjs FONT FLUIDSYNTH FFMPEG` with paths to the GeneralUser-GS SoundFont and the two executables. It writes the performances and their matching frame offsets. The normal game build uses the bundled recordings.

Earlier preview videos contain Kevin MacLeod’s *Monkeys Spinning Monkeys*. Its original recording and attribution are preserved with those releases. [Composer’s track page](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1400011) · [Credits for current and earlier recordings](../public/licenses/stadium-music.txt)

To regenerate the commentary track, install `kokoro-js` with `npm install --prefix .tooling/commentary kokoro-js@1.2.1` and run `node scripts/generate-commentary.mjs`. This optional step downloads the model once. Use `--append` to reuse locally cached phonetic guides whose IDs, voices and scripts match. Both commands render the complete cartoon bank. The game and normal build use the bundled asset.
